# GESOL — Albañilería, pintura y mantenimiento

Sitio web desarrollado para GESOL, un emprendimiento de Óscar Long que ofrece servicios de albañilería, pintura y mantenimiento en Juan Lacaze y todo el departamento de Colonia, Uruguay.

 [Visitar el sitio web](https://web-alba-ileria.vercel.app/)

## Sobre el proyecto

Este proyecto nace de una necesidad familiar: el poder ayudar a mi padre a dar a conocer su trabajo,
mostrando sus obras y el poder facilitar el contacto con nuevos clientes.

La propuesta es una combinación de desarrollo web y de mis conocimientos de marketing digital adquiridos en mi año estudiantil en UDE
el cual me ayudo para construir no solo una web, sino una presencia online orientada al público local.

## Funcionalidades

- Diseño adaptable a computadoras, tablets y celulares.
- Galería con fotografías reales de trabajos.
- Comparador interactivo de imagenes de antes y después.
- Formulario que valida los datos y prepara una consulta por WhatsApp.
- Enlaces directos a WhatsApp y al teléfono del negocio.
- Información sobre servicios y zona de cobertura.

El formulario abre WhatsApp con el mensaje preparado. El visitante revisa y envía la consulta desde la aplicación.

## Tecnologías utilizadas

- HTML5: estructura y contenido.
- CSS3: diseño, efectos visuales y adaptación a diferentes pantallas.
- JavaScript: comparador interactivo y lógica del formulario.
- Vercel: alojamiento del sitio.
- Git y GitHub: control de versiones y documentación.

## SEO local

El sitio web está preparado para poder facilitar el descubrimiento del mismo en búsquedas relacionadas
con albañilería, pintura y mantenimiento dentro de Juan Lacaze y Colonia.

Incluye:

- Título y descripción orientados a los servicios y la ubicación.
- Encabezados organizados y textos descriptivos.
- Texto alternativo en las imágenes.
- Datos estructurados JSON-LD con el tipo `HomeAndConstructionBusiness`, un subtipo de `LocalBusiness`.
- Información de contacto y área de servicio.
- URL canónica.
- Archivo `sitemap.xml`.
- Archivo `robots.txt`.

Estas medidas ayudan a los buscadores a interpretar el contenido, pero no garantizan una posición determinada en los resultados.

## Organización de los archivos

- `index.html`: estructura, contenido y metadatos.
- `styles.css`: estilos y diseño responsive.
- `script.js`: interacciones y formulario de WhatsApp.
- `assets/`: fotografías y logo.
- `screenshots/`: capturas utilizadas en este README.
- `robots.txt`: indicaciones de rastreo para buscadores.
- `sitemap.xml`: dirección de la página para los buscadores.

## Cómo ejecutarlo localmente

1. Descargar el repositorio o clonarlo.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir `index.html` en el navegador o utilizar Live Server.

No requiere instalar dependencias ni configurar una base de datos. Las fuentes de Google y el acceso a WhatsApp requieren conexión a Internet.
